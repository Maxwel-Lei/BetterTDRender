# BetterTDRender（BTDR）早期变更记录（0.1.0–0.7.2）

从 `IMPLEMENTATION_2.md` §13 移出（0.1.0–0.4.0 在 0.8.2，0.5.0–0.7.2 在 0.8.3），那份文档超过了一次能读完的长度。0.7.3 及以后的记录仍在 §13。
